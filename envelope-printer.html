3. Print Options

📋 USPS Compliance Notes:

  • Addresses are automatically formatted in UPPERCASE per USPS standards
  • Return address positioned at 0.5" from top and left edges
  • Mailing address centered on envelope (USPS OCR read zone)
  • #10 Envelope size: 4.125" x 9.5"
  • Make sure your printer is set to "Envelope #10" size
